One funny line from a hopeless tech support agent to a desperate customer, written by a small Node program to `/output/entry.txt`.

The agent's cheerful uselessness is the joke: after the classic "turn it off and on again", he commits to waiting on the line with the customer until his shift ends — solving nothing, together.

Built for the make.fun bounty [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) by [@xavier015869](https://make.fun/r/9d3wsaqp).

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
